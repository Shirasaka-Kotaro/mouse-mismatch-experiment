# 動作途中の仮想身体変化 実験アプリ

マウス操作の途中で、画面上の仮想カーソルへ視覚運動的不一致を加える実験用Webアプリです。

## 起動方法

`index.html` をブラウザで開くだけでも動作します。VS Codeでは、次のいずれかで確認できます。

1. `mouse-mismatch-experiment/index.html` を右クリックしてブラウザで開く
2. VS CodeのLive Server拡張機能でフォルダを開く
3. リポジトリ直下で簡易HTTPサーバーを起動する

例（Pythonがある場合）:

```powershell
python -m http.server 8000
```

その後、`http://localhost:8000/mouse-mismatch-experiment/` を開きます。

## 実験フロー

- ベースライン：通常のカーソル操作
- 摂動・適応：設定した摂動条件に適応する
- 後効果：摂動を解除し、通常状態へ戻した直後の動作を測定

初期値は、1ブロック12試行、8ブロック構成です。動作確認では1ブロック8試行に変更できます。

操作デバイスは「PCマウス」と「iPadタッチペン」から選択できます。デバイス名は保存データとファイル名に記録されます。

実験は「実験設定」→「実験」→「結果・分析」の3画面で進みます。設定画面では、参加者の利き手、年齢、実験で使用した手に加え、視力と課題中の矯正具装用、色覚、腕・手に影響する運動・神経疾患を入力できます。さらに、実験直前の眠気（1〜9・記入時刻）と、指・腕・肩・手首・首・全体の疲労度（1〜5）も記録します。

利き手、年齢、実験で使用した手などを選択して開始すると、設定画面から実験専用画面へ移ります。開始ボタンまたはブロック間の「次へ進む」を押した後には3秒のカウントダウンが表示され、その後に試行が始まります。全試行が終わると結果・CSV/JSON保存・適応曲線・軌道比較の画面へ移ります。

参加者IDを入力して「保存／上書き保存」を押すと、設定をブラウザの保存領域へ参加者IDごとに保存できます。同じIDで「保存設定を呼び出す」を押すと再利用でき、条件を変更してから同じボタンで上書きできます。保存はそのブラウザ内に限られるため、別PCや別iPadへ自動同期はされません。

## 摂動の開始タイミング

- 動作途中から：1回の動作中に起こるオンライン修正を測定します。
- 試行開始から：適応フェーズの各試行の開始時から摂動を提示し、運動適応曲線を作りやすくします。

## 摂動条件

実験開始前に、適応フェーズで使う条件を1つ選びます。ベースラインと後効果では、いずれの条件を選んでも通常のカーソル表示です。

- 重い：入力に対する仮想カーソルの追従を弱める
- 逆方向：動作途中から、マウスの移動方向を180°反転する
- 回転：動作途中から、マウスの移動方向を指定角度だけ回転する。正の角度は時計回り、負の角度は反時計回り

逆方向・回転条件では、摂動が始まる位置を基準に入力ベクトルを変換します。そのため、実際のマウス軌跡と画面上の仮想カーソル軌跡を比較できます。

## 保存データ

- CSV：試行ごとの要約値と軌跡を保存
- JSON：設定、乱数シード、ブロック結果、試行ごとの軌跡を保存

実験を始める前に参加者IDを設定し、セッション終了後にCSVまたはJSONを保存してください。

CSVファイル名は、例えば `P001_mouse_mismatch_trials.csv` または `P001_pencil_mismatch_trials.csv` になります。

## 運動適応曲線の作成

画面下部の「運動適応曲線」へ、保存したマウスCSVとタッチペンCSVを読み込みます。

- 横軸：選択したフェーズ内の試行回数
- 主指標：正規化終点誤差（終点誤差 ÷ ターゲット幅）
- 切り替え可能な指標：方向誤差、移動時間、実軌道長比、修正回数、成功率、マウス–カーソル距離
- 薄い点：各試行、太い線：指定した試行数の移動平均

「軌道の比較」では、実際の入力軌道と画面上のカーソル軌道を同じグラフへ表示できます。過去に保存した旧形式のCSVも、利用できる列から自動的に補って読み込めます。

## 主要な記録項目

- 実際のマウス軌跡
- 画面上の仮想カーソル軌跡
- 移動時間
- 仮想カーソルの終点誤差
- 成功・失敗
- 摂動開始時刻
- 摂動条件、回転角、摂動開始位置
- 軌跡長、修正回数、初期方向誤差
- 摂動後方向誤差、マウス–カーソル平均距離、軌跡長比
- 利き手、利き手ラベル、年齢、実験で使用した手
- 視力、矯正具の課題中装用、色覚、運動・神経疾患
- 眠気、眠気の記入時刻、指・腕・肩・手首・首・全体の疲労度
- FittsのIDとブロック別の傾き `b`
